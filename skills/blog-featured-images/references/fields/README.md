# Approved Fields Awaiting an Illustration

The user approved these backgrounds but not the illustrations they first carried. Use them only for a new layout with a real illustration (a card, a figure, logos), shown to the user first; never a background with only a headline.

| File | Field | What the user said |
| --- | --- | --- |
| `glow.webp` | the light blue glow from the retired `brandline` | "The bg looks good, can be used with some other illustration, but not like this with just a title heading." |
| `blue-mesh.webp` | the blue mesh gradient behind `versus/glass` | "The gradient is good but not looking good with this illustration. Can be used in some other illustration." |

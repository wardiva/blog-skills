# Approved Fields

The user approved these backgrounds but not the illustrations they first carried. A field is only ever used under a real illustration (a card, a figure, logos), shown to the user first; never a background with only a headline.

## In use

Since batch 5 (Oct 19 2026) the user picks each image's background on a picker page (`"bg": "<field>", "bgPick": true`; design language 3f). `soft`, `white`, `glow` and `mesh` are in the renderer's `BG_CSS` and come from that pick; the only fit lists that name them are the batch-6 and batch-7 card layouts', which lead with the field the user picked for the delivered image (`figures` white; `costgrid`, `versus/fan`, `versus/stacked` glow; batch 7: `strike` glow, `meter` white only). The other batch-7 layouts paint one approved field each (design language 3e): plain black, the deep dunes, `bluegrid`'s blue, the faint grid, our light glass, the light glow; never another brand's gradient or the navy-blob black ("use full black bg"; "use our good gradient bg"; `taste.md` 28). Across a batch, use the whole range, the strong fields too ("you are just using same color"; "we have multiple colors, black background color, blue gradient": `taste.md` 24).
